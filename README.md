# RoastMyFeed

Your taste. On trial. An AI-powered video-taste roast built from a sample you choose.

## Landing page

`index.html` is the self-contained landing page (no build step, no local assets).
Open it directly in a browser, or serve it statically (`npx serve .`).

Route placeholders to wire up as the app is built: `/start`, `/demo`, `/how-it-works`,
`/safety`, `/privacy`, `/terms`, `/support`.
